# 圆筒包装接缝避让

输入筒体周长、接缝安全宽度与若干毫米制印刷保护区，系统按周长归一化跨零点区间、合并禁用旋转范围、列出全部可行角度段，并默认选择距禁用边界最远、角度最小的旋转量。Canvas 同步预览接缝与保护区，拖动时吸附到最近可行位置；无解时展示覆盖整圈的禁用区间链。

## 方案快照与比较

- 「保存为快照」将当前周长、接缝宽度与保护区参数命名保存，数据持久化在浏览器 localStorage，刷新后仍在。
- 快照按保存时间列出，可逐条删除；勾选两个快照后点击「比较」，以时间较早者为基准，按圆周区间对**保护区、合并禁用段、可行段**分别计算差异：
  - **新增**（绿）：对比快照新出现的圆周区间；
  - **移除**（红）：基准快照中消失的圆周区间；
  - **边界移动**（蓝）：按圆周重叠配对的段，其起点/终点的有向偏移（分裂、合并与整圈段不误报为移动）。
- 比较结果在面板中分类列出，并在 Canvas 的三环（外＝可行段、中＝禁用段、内＝保护区）上分别高亮；点击「退出比较」返回实时计算视图。
- 比较接口：`POST /api/compare`，请求体 `{ "a": {circumference, seamWidth, zones}, "b": {...} }`（a 为基准），两者周长必须一致；返回各类别的 `added / removed / moved / unchanged` 区间列表。
